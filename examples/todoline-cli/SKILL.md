# todoline-cli

Agent skill for the `todoline-cli` API CLI (generated by clivane from an
OpenAPI 3 spec for Todoline API). One subcommand per operationId.

## Commands

- `create-todo` - POST /todos - Create a todo (JSON body via --body)
- `delete-todo` - DELETE /todos/{todoId} - Delete one todo by id
- `get-todo` - GET /todos/{todoId} - Fetch one todo by id
- `list-todos` - GET /todos - List todos, optionally filtered by completion state

## Conventions

- `--base-url` (or the environment variable) selects the API server.
- `--json` wraps responses as `{"status": int, "body": ...}`.
- Path and query parameters are flags; POST/PUT/PATCH take `--body '<json>'`.
